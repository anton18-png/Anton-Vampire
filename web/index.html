🛡️ Аудит безопасности и приватности

Три независимых аудита: Защита (21 проверка), Приватность (14), Удобство (13). Score от 1 до 6, рейтинг от «😾 Bogus» до «😹 Excellent».

  • Парсинг вывода ITEM|severity|id|name|result|expected
  • Firewall: правила «AV Allow / AV Block» для каждого .exe
  • NetMon: живой снимок TCP + резолв IP через PTR и ip-api
  • HTML-отчёты с тёмной темой через Save Dialog

🖱️ Курсоры с превью и умной ролью

Скачивание с GitHub, распаковка 7-Zip, установка в C:\Windows\Cursors\, активация через реестр и SystemParametersInfo — всё без перезагрузки.

  • Превью через nativeImage.createFromPath
  • 16 ролей с хинтами (Arrow, Wait, IBeam, Hand…)
  • Статусы «Скачан / Установлен / Активен»
  • Сброс всех курсоров на дефолт Windows

🚀 Автозагрузка без страха

4 источника: папки Startup, реестр Run/RunOnce, планировщик задач, службы. Каждый элемент категоризован (антивирус, телеметрия, Office, Edge, MS).

  • CRITICAL_SERVICES — 40+ защищённых служб
  • isCriticalTask() — 60+ запрещённых задач
  • Safe / Advanced режимы (localStorage)
  • Иконки через app.getFileIcon()

💼 Portable Mode из коробки

Все данные — конфиг, логи, обои, курсоры, бэкапы — лежат в extreme_data/ рядом с exe. В системе ничего не остаётся.

  • app.setPath('userData', …) для Chromium
  • Отдельные папки для session, cache, crashDumps
  • Отключены disable-breakpad и no-crash-upload
  • Переносится на флешке, работает без установки
