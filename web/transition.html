Extreme Tweaker → Anton Vampire

Один монолитный Python-скрипт на 5000 строк — и полностью переписанное Electron-приложение на ~25 модулях. Ниже — что именно поменялось, что удалено, что добавлено и почему.

Extreme Tweaker
v3.7.3.5 / v4 Beta · Python · tkinter
  • Python 3.7+ в PATH
  • PyInstaller → SetupWinterWizard.exe
  • Монолит main.py (~5000 строк)
  • Статические словари в tabs_beta.py
  • configparser · settings.ini · cp1251
  • ~15 тем в user.py + ttkbootstrap
  • Один шрифт на всё
  • Telegram-телеметрия через telebot
  • Автообновление через curl
  • Pro-версия за донат
➜
Anton Vampire
v1.0.0-beta · Electron 44 · Node.js
  • Никаких внешних зависимостей — всё в бандле
  • electron-builder → NSIS installer
  • ~25 модулей по 100–600 строк
  • Внешние JSON-источники твиков
  • JSON · settings.json · UTF-8 · debounce
  • ~80 тем в groups + Material You
  • 6 шрифтовых слотов + веса 100–900
  • Никакой телеметрии
  • Обновления через GitHub Releases
  • Всё Free, open source

5 · Запуск твиков

8 · Итог

Что осталось тем же

Концептуально Anton Vampire — та же программа: та же идея, та же база твиков, тот же язык и та же ОС.

🩸
Та же идея

Запускать .bat/.cmd/.ps1/.exe/.reg/.pow твики с чекбоксами.

🗂
Та же база твиков

Папка tweaks/, папка Utils/, папка assets/, descriptions.txt.

🎨
4 режима чекбоксов

regular (Hone), rectangle (All Tweaker), wide (BoosterX), sapphire (BoosterX-совместимый).

⚙
Требует админа

Оба приложения требуют права администратора для глубоких изменений.

🇷🇺
Русский язык

Весь интерфейс, описания и документация — на русском.

🪟
Windows 10/11

Только Windows. Linux/macOS не поддерживаются.
