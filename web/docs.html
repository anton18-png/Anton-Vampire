Anton Vampire

Полный справочник по приложению: установка, интерфейс, все 11 вкладок, темы, шрифты, настройки, безопасность, курсоры, обои и сборщики.

Начало

Введение

Anton Vampire — полностью переписанный на Electron Windows оптимизатор. Наследник Extreme Tweaker (Python/tkinter) с сохранением концепции: запуск .bat/.cmd/.ps1/.exe/ .reg/.pow твиков через удобный UI.

Внутри — 1000+ твиков, сгруппированных по 11 вкладкам, ~80 тем, Cyberpunk 2077 интерфейс, аудит безопасности, управление автозагрузкой, курсоры, обои, HTML-отчёты и сборщики JSON-данных.

Open Source

MIT-подобная лицензия, весь код на GitHub.

Portable

Всё в extreme_data/ рядом с exe.

Без зависимостей

Electron + Node.js уже в бандле.

Windows 10/11

Только Windows, x64.

⚠
Требуются права администратора. Приложение проверяет fltmc при старте и предлагает перезапуск с UAC через Start-Process -Verb RunAs.

Установка

Установка

Способ 1: одной командой

Откройте Win + R → cmd и вставьте:

curl -g -k -L -# -o "%temp%\AntonVampire.Setup.exe" "https://github.com/anton18-png/Anton-Vampire/releases/download/v1.0.4-beta/Anton.Vampire.Setup.1.0.4-beta.exe" && start "" "%temp%\AntonVampire.Setup.exe"

Способ 2: Setup вручную

  1. Скачайте Anton.Vampire.Setup.1.0.4-beta.exe
  2. Запустите — UAC запросит подтверждение
  3. Следуйте инструкциям установщика NSIS

Способ 3: Portable

Скачайте Anton.Vampire.Portable.rar, распакуйте в любую папку и запустите AntonVampire.exe. Все данные лягут в extreme_data/ рядом с exe.

Способ 4: из исходников

git clone https://github.com/anton18-png/Anton-Vampire.git
cd Anton-Vampire
npm install
npm start
✓
Проверка: после запуска откройте Настройки → О программе — там будет версия и кнопка «↺ Сбросить все настройки».
UI

Интерфейс

Приложение состоит из 5 постоянных элементов:

  1. Сайдбар — разворачивается по hover, 11 разделов
  2. Топбар — драг-зона окна, поиск, кнопки
  3. Табы — под-вкладки внутри раздела
  4. Content — содержимое активной вкладки
  5. Статус-бар — статус и счётчик выбранных

Сайдбар

В свёрнутом виде — только иконки (--sidebar-collapsed: 60px). При hover разворачивается до --sidebar-expanded: 216px за 250ms.

Топбар

  • Лого + версия
  • Глобальный поиск #global-search
  • Кнопки: Выделить всё, ▶ Выполнить, ♻ Обновить, ⛶ Fullscreen
Механика

Темы и шрифты

Темы

В renderer/themes.js экспортируется объект THEMES (~80 ключей) и THEMES_META.groups (10 групп). Применение — applyTheme(name, unified, sidebarOpacity).

cyberpunk_2077: {
  bg: '#090507', bgAlt: '#11070a', card: '#180a10', cardHover: '#24101a',
  border: '#ff003c', fg: '#f0f0f0', fgMuted: '#8a7a7a',
  accent: '#00e5ff', accent2: '#ff003c', accentText: '#000000',
  success: '#00e5ff', warning: '#fcee0a', danger: '#ff003c', info: '#00b0c0'
}

Шрифты

6 слотов + 2 веса:
