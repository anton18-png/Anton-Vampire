Anton Vampire

Полный справочник по приложению: установка, интерфейс, все 11 вкладок, темы, шрифты, настройки, безопасность, курсоры, обои и сборщики.

Начало

Введение

Anton Vampire — полностью переписанный на Electron Windows оптимизатор. Наследник Extreme Tweaker (Python/tkinter) с сохранением концепции: запуск .bat/.cmd/.ps1/.exe/ .reg/.pow твиков через удобный UI.

Внутри — 1000+ твиков, сгруппированных по 11 вкладкам, ~80 тем, Material You интерфейс, аудит безопасности, управление автозагрузкой, курсоры, обои, HTML-отчёты и сборщики JSON-данных.

Open Source

MIT-подобная лицензия, весь код на GitHub.

Portable

Всё в extreme_data/ рядом с exe.

Без зависимостей

Electron + Node.js уже в бандле.

Windows 10/11

Только Windows, x64.

⚠
Требуются права администратора. Приложение проверяет fltmc при старте и предлагает перезапуск с UAC через Start-Process -Verb RunAs.

Установка

Установка

Способ 1: одной командой

Откройте Win + R → cmd и вставьте:

curl -g -k -L -# -o "%temp%\AntonVampire.Setup.exe" "https://github.com/anton18-png/Anton-Vampire/releases/download/v1.0.2-beta/Anton.Vampire.Setup.1.0.2-beta.exe" && start "" "%temp%\AntonVampire.Setup.exe"

Способ 2: Setup вручную

  1. Скачайте Anton.Vampire.Setup.1.0.2-beta.exe
  2. Запустите — UAC запросит подтверждение
  3. Следуйте инструкциям установщика NSIS

Способ 3: Portable

Скачайте Anton.Vampire.Portable.rar, распакуйте в любую папку и запустите AntonVampire.exe. Все данные лягут в extreme_data/ рядом с exe.

Способ 4: из исходников

git clone https://github.com/anton18-png/Anton-Vampire.git
      cd Anton-Vampire
      npm install
      npm start
✓
Проверка: после запуска откройте Настройки → О программе — там будет версия и кнопка «↺ Сбросить все настройки».
UI

Интерфейс

Приложение состоит из 5 постоянных элементов:

  1. Сайдбар — разворачивается по hover, 11 разделов
  2. Топбар — драг-зона окна, поиск, кнопки
  3. Табы — под-вкладки внутри раздела
  4. Content — содержимое активной вкладки
  5. Статус-бар — статус и счётчик выбранных

Сайдбар

В свёрнутом виде — только иконки (--sidebar-collapsed: 60px). При hover разворачивается до --sidebar-expanded: 216px за 250ms с cubic-bezier(0.2, 0, 0, 1). Снизу — 5 иконок: тема, звук, фон, Telegram, донат.

Топбар

  • Лого + версия
  • Глобальный поиск #global-search — фильтрует чекбоксы по имени
  • Кнопки: Выделить всё, ▶ Выполнить, ♻ Обновить, ⛶ Fullscreen, — Свернуть, ✕ Закрыть

Панель лога

Внизу экрана фиксированная панель (#log-panel), свёрнутая по умолчанию в 30px. При запуске твиков разворачивается и стримит stdout/stderr построчно. Кнопки: ▾ свернуть, ✕ очистить.

Тосты

Плавающие уведомления в правом нижнем углу. 4 типа: info, success, warning, error.

Вкладка 2

🛡️ Безопасность

Три под-вкладки с независимыми аудитами:

АудитПроверокЧто оценивает
Безопасность21UAC, BitLocker, SMBv1, LSA, SmartScreen, DEP/ASLR, WDigest, LLMNR, Remote Registry, PowerShell v2 и др.
Приватность14Телеметрия, геолокация, рекламный ID, User Activities, CDP, Sync, WER, NVIDIA Telemetry
Удобство13Defender, UAC, SmartScreen, Windows Update, Firewall (антагонист «Безопасности»)

Формат вывода .bat

ITEM|Passed|S01|UAC|Включён|Включён
ITEM|Medium|S04|WDigest|Включён|Отключён
ITEM|High|P03|Telemetry|1|0
END|score=4.12|percent=68|grade=Well done|passed=14|low=3|medium=3|high=1|total=21

Парсер parseBatOutput читает построчно, ищет ITEM| и END|. Score = (набрано / максимум) × 5 + 1. Рейтинг: 1 — 😾 Bogus, 2 — 😿 Weak, 3 — 🙀 You should do better, 4 — 😺 Sufficient, 5 — 😻 Well done, 6 — 😹 Excellent.

Firewall

Отдельная секция для каждого .exe:

  • Кнопка «➕ Добавить программу» → New-NetFirewallRule -Direction Outbound
  • Правила именуются AV Allow: <name> / AV Block: <name>
  • При включении Block — конфликтующие Allow автоматически отключаются
  • Toggle для всех профилей: Set-NetFirewallProfile -Profile Domain,Public,Private

NetMon (Сетевой монитор)

Живой снимок TCP-соединений (Get-NetTCPConnection -State Established) и локальных портов (-State Listen). Резолв IP:

  • none — только IP
  • ptr — стандартные PTR-записи (1e100.net, cloudfront.net)
  • brand — через ip-api.com → «Google», «Telegram», «Discord» и т.д.

HTML-отчёты

Кнопки «📄 Все отчёты» и «📄 Экспорт». Генерируется самодостаточный HTML с тёмной темой, статистикой, таблицами проверок и статусом firewall. Сохраняется через dialog.showSaveDialog.

Вкладка 3

🚀 Автозагрузка

4 источника + 2 режима (Safe / Advanced).

Источники

  • Папки — %APPDATA%\...\Startup (user) и %ProgramData%\...\Startup (system). Отключение — переименование в .disabled
  • Реестр — HKCU\Run, RunOnce, HKLM\Run, RunOnce, WOW6432Node\.... Отключение — перенос значения в _disabled-ключ
  • Задачи — Get-ScheduledTask, фильтр по MSFT_TaskLogonTrigger / MSFT_TaskBootTrigger. Toggle через Enable/Disable-ScheduledTask
  • Службы — Get-CimInstance Win32_Service. Toggle через sc config start= auto|disabled

Категории

🛡 Антивирус

Defender, Kaspersky, Avast, ESET

📡 Телеметрия

DiagTrack, dmwappush, PCA

🌊 Edge

msedge, edgeupdate

📄 Office

Word, Excel, Outlook

🪟 MS-программы

OneDrive, Teams, Xbox, Spotify, Steam

Защита критичных

CRITICAL_SERVICES — 40+ служб (RpcSs, DcomLaunch, PlugPlay, Power, ProfSvc, Themes, Winmgmt, EventLog, Disk, …) — не показываются.

isCriticalTask() — 60+ запрещённых путей (Microsoft\Windows\UpdateOrchestrator, Windows Defender, Servicing, AppxDeploymentClient, …). У задач и папок защищённые элементы показываются с 🔒, но их нельзя toggle/delete.

Режимы

  • Safe (по умолчанию) — только элементы с категорией или user-элементы
  • Advanced — все элементы, кроме критичных

Описания берутся из tweaks/descriptions.txt через window.api.tweaks.describe() и кэшируются на 5 минут с фоновой чисткой каждую минуту.

Патчинг .bat

Перед запуском _makePatchedBat():

  • Удаляет BOM и echo off / chcp (заменяет на свой header)
  • Вырезает pause, timeout, choice (заменяет на rem)
  • Патчит start → start /b "" (или start /b если title уже был)
  • Подставляет %~dp0, %~f0, %~n0 в абсолютные пути
  • Пишет результат рядом с оригиналом (не в %TEMP%), чтобы %~dp0 работал

Стрим

runStream и runCommandStream шлют tweaks:stream-data и tweaks:stream-end. Рендерер подписывается на события и пишет в панель лога.

Кодировка

Вывод декодируется через UTF-8, при наличии U+FFFD — fallback на ibm866 (cp866). Это спасает старые .bat в OEM-кодировке.

Таймаут

По умолчанию 300 000 мс (5 минут). По истечении — SIGKILL и exit code -2. Настраивается в Настройки → Интерфейс.

flatCategories

Флаг у источника. Если true — файлы лежат прямо в baseDir, категория в JSON — логическая метка. Если false — путь baseDir/Категория/file.

Пары «твик ↔ отмена»

buildPairMap(rootFiles, cancelFiles) нормализует имена через coreName(): убирает префиксы-глаголы (включить, отключить, вернуть, восстановить, сбросить, откатить, показать, скрыть, разблокировать, установить, …), расширение и служебные символы.

Если core-имя совпало — рядом с карточкой появляется кнопка ↩, которая запускает парный файл. Показ кнопок отмены настраивается (show_cancel_buttons).

FAQ

Частые вопросы

Почему антивирус ругается?

Три причины:

  • Нет цифровой подписи (сертификат $300–500/год)
  • Приложение меняет реестр, службы и системные файлы — для антивируса это подозрительно
  • Приложение использует NSudoLG.exe, PowerRun.exe, cmd.exe — часто встречаются в malware

Добавьте папку в исключения. Код открыт на GitHub.

Где хранятся настройки?

В extreme_data/settings.json рядом с AntonVampire.exe. В AppData ничего не пишется.

Почему требует админа при каждом запуске?

Приложение проверяет fltmc и, если прав нет, показывает диалог с кнопкой «Перезапустить» → Start-Process -Verb RunAs с флагом --relaunch.

Как сбросить все настройки?

Настройки → О программе → «↺ Сбросить все настройки». Или удалите extreme_data/settings.json вручную.

Где взять сборщики JSON?

Они лежат в корне проекта (рядом с main.js) или в релизном архиве. Запустить можно из Настройки → Утилиты. Требуется Python 3.8+ в PATH.

Как добавить свои твики?
  1. Положите .bat / .ps1 / .exe / .reg в нужную папку tweaks/<button>/<tab>/
  2. Добавьте описание в tweaks/descriptions.txt (формат filename.bat=Описание)
  3. Откройте Настройки → Утилиты → build_all_tabs.py → «▶ Запустить»
  4. Готово — твик появится во вкладке
Что такое Sapphire и почему он не работает?

Sapphire — 4-й режим чекбоксов (2 колонки с раскрывающимся описанием). В текущей бете он пока не реализован: при выборе рендерится BoosterX. Классы .cbx-sf* в CSS уже есть, но renderSapphire в checkbox.js не написан.

Можно ли использовать без интернета?

Да, всё локальное. Сеть нужна только для: загрузки курсоров с GitHub, скачивания обоев по URL, резолва IP в NetMon (если mode=brand).

Troubleshooting

Troubleshooting

Приложение не запускается

  • Проверьте, что запускаете от админа
  • Если UAC отменён — приложение закроется. Нажмите «Перезапустить» в диалоге
  • Включите General.logs_enabled = true в settings.json, посмотрите extreme_data/logs/

Твик зависает

  • По умолчанию таймаут 5 мин. Увеличьте в Настройки → Интерфейс
  • Возможен конфликт с антивирусом — добавьте папку в исключения
  • Попробуйте сменить режим запуска: nsudolg → powerrun → cmd

Кракозябры в логе

Твик выводит в OEM-кодировке (cp866). Приложение пытается декодировать UTF-8, при ошибке — fallback на cp866. Если кракозябры всё равно — пересохраните .bat в UTF-8 через Notepad++.

Открывается окно консоли при запуске твика

В .bat есть start. Приложение патчит его на start /b "" перед запуском. Если окно всё равно открывается — вероятно, внутри вызывается внешний .exe или используется start cmd (это игнорируется).

Не работает поиск

Поиск фильтрует только по name чекбоксов на текущей вкладке. Для глобального поиска введите запрос в #global-search в топбаре. Кэш описаний сбрасывается кнопкой «♻ Обновить».

Курсоры не применяются

  • Убедитесь, что в архиве есть .cur/.ani
  • Проверьте, что папка C:\Windows\Cursors\<name>\ создана
  • Попробуйте «▶️ Применить» ещё раз — иногда Windows не применяет с первого раза
  • Сбросьте всё через «🗑️ Удалить все»
ℹ
Логи: включите logs_enabled в настройках. Файлы появятся в extreme_data/logs/{user}_log_{ts}.log и {user}_errors_{ts}.log. Ошибки также дублируются в консоль.
